# Miniprojeto: inventário de TI

Junta listas, dicionários/conceitos de registros, funções e classes. Execute `python projetos/inventario-ti/inventario.py` na raiz do repositório.

**Próximos desafios:** buscar pelo nome, cadastrar computadores pelo terminal, salvar em JSON e acrescentar testes. Os IPs e estados são exemplos fictícios; este programa não verifica a rede.
